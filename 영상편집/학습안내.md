# 영상편집: 초보자가 알아야 할 것

목표는 시청자가 내용을 쉽게 따라가게 만드는 것입니다. 처음에는 편집 프로그램 하나를 골라 아래 기능을 익히세요.

## 1. 꼭 알아둘 기능과 용어

| 용어 | 의미와 첫 연습 |
|---|---|
| 프로젝트 | 편집 결정과 소재 연결을 저장하는 파일. 저장 위치부터 정하기 |
| 타임라인 | 영상·소리를 시간 순으로 배치하는 작업 공간 |
| 트랙 | 화면·음성·음악·자막을 층으로 나누어 배치하는 자리 |
| 분할·트림 | 클립을 자르거나 시작·끝을 줄이기 |
| 리플 삭제 | 삭제한 구간의 빈자리까지 당겨 없애기. 다른 트랙의 싱크 확인 |
| 키프레임 | 시간에 따라 위치·크기·음량을 바꾸는 기준점 |
| 프록시 | 편집을 가볍게 하는 저용량 대리 파일. 출력 전 원본 연결 확인 |
| 내보내기 | 프로젝트를 재생 가능한 동영상 파일로 만들기 |

프로젝트 파일은 완성 영상이 아닙니다. 원본과 함께 보관하고 자주 저장하세요.

## 2. 편집 순서

1. 소재 가져오기: 영상·음성·음악을 구분하고 화면 비율과 fps를 확인합니다.
2. 러프 컷: 대본 순서로 놓고 실수·중복·불필요한 대기를 지웁니다.
3. 흐름 다듬기: 필요한 호흡은 남기고, 핵심 설명마다 해당 예시 화면을 붙입니다.
4. 소리: 별도 녹음과 화면을 맞추고, 대사 음량을 일정하게 조절합니다. 배경음악은 말을 가리지 않게 낮춥니다.
5. 자막: 맞춤법·고유명사·숫자를 검토하고 휴대전화에서도 읽히는지 봅니다. 자동 자막도 직접 검수합니다.
6. 색과 밝기: 장면 사이 밝기·색 차이를 줄입니다. 과한 필터보다 자연스러운 얼굴색을 기준으로 삼습니다.
7. 내보내기와 전체 검수: 출력한 파일을 처음부터 끝까지 재생합니다.

전환 효과를 모든 컷에 넣을 필요는 없습니다. 먼저 단순한 컷 연결로 내용을 전달해 보세요. 음성 잡음 제거를 과하게 쓰면 목소리가 부자연스러워질 수 있습니다.

## 3. 출력 연습 기준

첫 가로 영상은 MP4, H.264, 1920×1080, 촬영·타임라인과 일치하는 fps로 연습할 수 있습니다. 오디오는 AAC를 사용할 수 있습니다. 이는 시작용 설정이며 모든 영상의 필수 규격은 아닙니다. 세로 영상은 세로 타임라인에서 주요 대상과 자막 위치를 다시 확인합니다.

출력 후 검은 화면, 잘린 자막, 무음, 소리 찢어짐, 음성 싱크, 마지막 잔여 화면을 점검하세요. 이어폰과 휴대전화 스피커로 각각 들어 봅니다.

## 4. 외부 소재 기록

음악·이미지·폰트·효과음마다 출처, 이용 조건, 필요한 표기, 확인일을 기록합니다. 무료 다운로드가 자유로운 재사용을 뜻하지는 않습니다. YouTube 오디오 보관함도 트랙별 저작자 표시 조건을 확인하세요.
[공식 오디오 보관함 안내](https://support.google.com/youtube/answer/3376882?hl=ko)

## 첫 실습과 완료 기준

촬영한 30초 설명을 20~30초로 다듬고 보충 화면 3개, 필요한 자막, 작은 배경음악을 붙여 출력합니다.

- [ ] 제목에서 약속한 정보가 영상에 있다.
- [ ] 중요한 말을 잘라 뜻이 바뀌지 않았다.
- [ ] 목소리가 잘 들리고 자막을 읽을 수 있다.
- [ ] 외부 소재의 이용 조건을 기록했다.
- [ ] 출력 파일 전체를 검수했다.
- [ ] 프로젝트와 원본 연결이 유지된다.

자주 하는 실수: 효과부터 꾸미기, 배경음악이 대사를 덮기, 자동 자막 그대로 사용하기, 출력 파일 확인 없이 업로드하기.
