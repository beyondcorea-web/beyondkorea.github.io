# 유튜브 운영 첫걸음

목표: 기획 → 제작 → 편집 → 게시 → 개선을 직접 한 번 경험합니다.
처음에는 스마트폰과 현재 사용할 수 있는 편집 프로그램으로 시작하세요. 이 자료는 특정 프로그램에 종속되지 않습니다.

## 읽는 순서

1. [영상 기획](영상%20기획/학습안내.md): 누구에게 어떤 도움을 줄지 정하기
2. [영상 제작](영상%20제작/학습안내.md): 대본을 촬영·녹음 자료로 바꾸기
3. [영상편집](영상편집/학습안내.md): 시청자가 이해하기 쉽게 연결하기
4. [영상게시](영상게시/학습안내.md): 업로드하고 결과를 다음 기획에 반영하기

각 폴더의 `실습양식.md`를 복사해서 영상마다 작성하세요. 같은 영상 번호(예: EP001)를 네 단계에서 함께 사용하면 찾기 쉽습니다.

## 4주 학습 계획

| 기간 | 할 일 | 완료 기준 |
|---|---|---|
| 1주 | 시청자 정하기, 아이디어 10개, 기획안과 대본 | 2~3분 영상 한 편의 촬영 계획 |
| 2주 | 10초 테스트 후 본 촬영, 보충 화면, 파일 백업 | 편집 가능한 원본과 녹음 확보 |
| 3주 | 컷 편집, 음성, 자막, 색, 출력 | 처음부터 끝까지 검수한 MP4 |
| 4주 | 제목·썸네일, 비공개 업로드, 검수, 게시, 회고 | 첫 영상 완성과 다음 개선점 1개 |

위 기간과 영상 길이는 연습용 제안입니다. 일정보다 한 편을 끝까지 완성하는 것이 우선입니다.

## 파일 관리

- 예: `EP001_주제_20261027_v01.mp4`. 수정할 때 v02, v03으로 구분합니다.
- 원본, 편집 프로젝트, 최종 출력은 구분하여 보관합니다. 프로젝트 파일만으로는 원본이 복구되지 않습니다.
- 원본은 다른 저장장치에도 복사하고, 복사본이 열리는지 확인합니다. 동기화만으로 모든 삭제 사고를 막을 수는 없습니다.
- GitHub에는 학습 문서·기획안·체크리스트를 중심으로 보관합니다. 대용량 영상은 별도 저장소를 사용하세요.
- 연결된 GitHub 저장소는 공개입니다. 개인정보, 비밀번호, 비공개 촬영 동의서, 미공개 고객 자료를 커밋하지 마세요.

## 첫 달의 성공 기준

- [ ] 네 단계를 거쳐 영상 한 편을 완성했다.
- [ ] 시청자가 얻는 이점을 한 문장으로 말할 수 있다.
- [ ] 휴대전화에서도 말소리와 자막이 이해된다.
- [ ] 사용한 자료의 출처와 이용 조건을 기록했다.
- [ ] 다음 영상에서 바꿀 점을 하나 정했다.

공식 정책과 기능은 바뀔 수 있습니다. 게시 폴더의 공식 도움말을 실제 게시 전에 확인하세요.
