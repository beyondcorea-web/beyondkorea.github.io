# 영상게시: 초보자가 알아야 할 것

목표는 영상이 의도대로 재생되고 시청자가 찾고 이해할 수 있도록 게시한 뒤, 결과를 다음 기획에 반영하는 것입니다.

## 1. 채널과 계정 준비

채널 이름·설명·프로필을 정하고 어떤 내용을 다룰지 일관되게 안내합니다. 계정 복구 수단과 2단계 인증을 점검하세요. YouTube Studio에서 콘텐츠·분석·댓글 메뉴가 어디에 있는지 익힙니다. 계정별로 사용 가능한 기능이 다를 수 있으므로 Studio의 안내를 확인합니다.

## 2. 제목·썸네일·설명

- 제목: 대상 시청자와 얻을 결과를 구체적으로 표현합니다. 영상에 없는 결과를 약속하지 않습니다.
- 썸네일: 작은 화면에서 중심 대상이 구분되고 문구가 읽히는지 봅니다. 제목과 함께 영상의 핵심을 전달합니다.
- 설명: 영상 요약, 참고 자료, 음악 등 필요한 저작자 표시, 관련 링크를 적습니다.
- 재생목록: 같은 주제의 영상을 묶습니다.
- 자막: 자동 인식 결과의 이름·숫자·전문용어를 확인합니다.

맞춤 썸네일과 Shorts 관련 기능은 계정과 사용 환경에 따라 확인이 필요합니다.
[공식 썸네일 안내](https://support.google.com/youtube/answer/72431?hl=ko)

## 3. 업로드 순서

1. Studio에 최종 파일을 업로드하고 제목·설명·썸네일을 입력합니다.
2. 실제 대상 시청자에 맞게 아동용 여부를 판단합니다. 아동용 설정은 ‘모든 연령이 볼 수 있다’는 뜻과 다릅니다.
3. 해당하는 경우 유료 프로모션과 변경·합성 콘텐츠 관련 질문을 확인하여 실제 내용에 맞게 응답합니다.
4. 저작권 등 검사 결과와 제한 안내를 확인합니다. 자동 검사에 문제가 없더라도 사용 권한 기록은 보관합니다.
5. 비공개 상태에서 처리 완료 후 재생 품질·음성·자막·링크를 확인합니다.
6. 공개 또는 예약 게시를 선택하고 날짜·시간대를 확인합니다. 게시 후 공개 페이지를 다시 확인합니다.

비공개는 접근을 제한하는 방식이고, 일부 공개는 링크를 아는 사람이 볼 수 있는 방식입니다. 검토용 링크를 공유할 때 차이를 기억하세요.
[공식 업로드 안내](https://support.google.com/youtube/answer/57407?hl=ko)
[아동용 판단 안내](https://support.google.com/youtube/answer/9528076?hl=ko)

## 4. 게시 후 배우는 법

처음에는 조회수만으로 성공과 실패를 결정하지 마세요. 예를 들어 게시 48시간 뒤와 7일 뒤에 기록하되, 이는 학습용 점검 일정이며 플랫폼의 평가 기한은 아닙니다.

| 지표 | 의미 | 확인하고 시도할 것 |
|---|---|---|
| 노출수 | 집계 조건을 충족해 썸네일이 표시된 횟수 | 유입 경로와 주제 확인 |
| 노출 클릭률 | 집계된 노출 중 시청으로 이어진 비율 | 제목·썸네일이 내용을 잘 설명하는지 |
| 평균 시청 지속 시간 | 평균적으로 시청한 시간 | 영상 길이와 함께 비교 |
| 시청 지속률 | 구간별로 얼마나 시청을 이어갔는지 | 이탈 구간의 긴 인사·반복·혼란 점검 |
| 유입 경로 | 검색·홈·외부 등 시청자가 온 곳 | 어떤 질문과 상황에서 찾았는지 |
| 댓글 | 시청자의 질문과 반응 | 다음 영상에서 답할 질문 찾기 |

노출수는 모든 화면 표시나 외부 유입을 포함하지 않습니다. Shorts와 일반 영상은 시청 방식과 제공 지표가 다르므로 같은 기준으로 단순 비교하지 마세요. 작은 표본의 클릭률을 과신하지 말고 주제·길이·유입 경로가 비슷한 영상과 비교합니다. 다음 영상에서 바꿀 요소는 하나씩 정합니다.
[공식 노출수·시청 시간 안내](https://support.google.com/youtube/answer/9314486?hl=ko)

## 첫 실습과 완료 기준

- [ ] 제목·썸네일·영상의 약속이 일치한다.
- [ ] 출처와 필요한 표시를 작성했다.
- [ ] 아동용 등 설정을 실제 내용에 맞게 확인했다.
- [ ] 비공개 재생 검수를 마쳤다.
- [ ] 공개 범위·예약 시간·시간대를 확인했다.
- [ ] 게시 후 링크와 화면을 확인했다.
- [ ] 성과와 다음 개선점 1개를 기록했다.
